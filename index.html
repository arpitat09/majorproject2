Criteria #2 — Research Gap

Identification of Research Gap

Detection Gaps

  • Limited capability to handle zero-day or previously unseen attacks in IIoT environments
  • Minority attack classes (U2R, R2L) consistently under-detected with <70% rate despite high overall accuracy
  • Most models depend heavily on specific datasets and may not generalize well across IIoT scenarios

Prevention Gaps

  • 83% of surveyed papers focus only on detection (IDS), lacking integrated prevention system (IPS)
  • The few IPS approaches use simplistic rule-based blocking without intelligent response adaptation
  • No paper combines detection accuracy with graded prevention responses

Performance Gaps

  • Several models are accurate but too complex for real-time IIoT deployment (>40ms inference vs <10ms needed)
  • Deep learning approaches (LSTM, Transformer) have highest accuracy but exceed IIoT resource constraints
  • Lightweight models sacrifice too much accuracy for speed

Methodology Gaps

  • Many studies focus on only one aspect — static analysis, behavioral analysis, or network-based — not combined
  • Privacy-preserving and cloud-based methods often introduce extra overhead reducing practicality
  • Single-dataset evaluation leads to overfitted results not reproducible across environments

Criteria #3 — Soundness of Proposed Solution

Soundness of Proposed Solution

Detection Strength

  • Combines multiple indicators (unsupervised anomaly + supervised classification) instead of relying on a single feature or model
  • Uses behavior-based monitoring for early detection before encryption/damage begins
  • Can improve detection of unknown and evolving attack variants through Tier-1 unsupervised layer
  • SMOTE-ENN directly addresses minority class imbalance (GAP-2)

Prevention Strength

  • First framework to integrate intelligent IPS with severity-graded responses (Alert → Rate-limit → Block → Terminate)
  • More practical than purely signature-based methods — adapts to attack type and severity
  • Feedback loop from prevention outcomes improves future detection accuracy
  • Directly addresses the detection-prevention disconnect (GAP-1)

Performance Strength

  • Tree-based Tier-2 (XGBoost + LightGBM) provides <10ms inference — suitable for real-time IIoT (GAP-3)
  • Multi-dataset evaluation (NSL-KDD + CICIDS2017 + BoT-IoT) eliminates single-dataset bias (GAP-4)
  • Supports faster response before major damage occurs in industrial processes

Trust & Adoption

  • SHAP explainability provides reasoning for each detection decision — critical for IIoT operators (GAP-5)
  • Technically aligned with current research needs identified in literature
  • Proposed solution is directly derived from the gaps identified from literature review
  • Modular architecture allows incremental adoption in existing IIoT setups

Criteria #5 — Technical Depth

Technical Depth and Clarity

Algorithm Coverage

  • Studies both detection (Tier 1 + Tier 2) and prevention (Tier 3) aspects comprehensively
  • Covers advanced methods: ML (RF, SVM, XGBoost), DL (LSTM, CNN), RL (DQN), graph-based, anomaly detection, and ensemble approaches
  • Proposed hybrid framework combines unsupervised + supervised + rule-based — covering the full spectrum

Data & Evaluation Rigor

  • Includes cloud security and privacy-aware approaches in literature review
  • Multi-dataset evaluation eliminates single-dataset overfitting concern
  • Clearly compares strengths and limitations of all 40 existing methods
  • Evaluation metrics: Accuracy, F1-Score, Detection Rate, False Alarm Rate, Inference Time

Preprocessing Detail

  • 6-step preprocessing pipeline: Cleaning → Scaling → Feature Selection → PCA → SMOTE-ENN → Stratified CV
  • RobustScaler chosen over StandardScaler for outlier resistance in IIoT bursty traffic
  • Nested cross-validation (inner 3-fold, outer 5-fold) prevents optimistic bias in hyperparameter tuning
  • SMOTE-ENN applied only on training set to prevent data leakage

Explainability & Trust

  • TreeSHAP provides O(TLD) time complexity explainability for tree-based models
  • Top-5 contributing features per prediction displayed on dashboard
  • Addresses the critical trust gap between ML models and IIoT human operators
  • Enables rapid incident response through interpretable threat reasoning
